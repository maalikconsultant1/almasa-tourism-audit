Title: almasa-tourism-audit
Description:

A lean, static micro-SaaS landing page for UAE Compliance Audit & Golden Visa Support by ALMASA Tourism. Built with zero dependencies, this single-page solution delivers a human-reviewed FTA compliance risk assessment within 24 hours via WhatsApp. Accepts payments in USDT (TRC-20) and integrates a Tally.so intake form (rjarEo) for seamless lead capture. Deployed on Vercel with clean routing via vercel.json.
